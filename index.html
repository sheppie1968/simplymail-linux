SimplyMail for Linux

Email, calendar, contacts and tasks for your own IMAP and POP3 accounts. Version 1.0.18, for 64-bit Ubuntu 24.04 or newer, Linux Mint 22 or newer, and Debian 13 or newer.

Install with updates (recommended)

Run these in a terminal. New versions then arrive with your system's normal updates.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/simplymail.gpg https://simplymail.wizzard.co.za/simplymail-linux/simplymail.gpg
echo "deb [signed-by=/etc/apt/keyrings/simplymail.gpg] https://simplymail.wizzard.co.za/simplymail-linux stable main" | sudo tee /etc/apt/sources.list.d/simplymail.list
sudo apt update
sudo apt install simplymail

Or download the package

simplymail_1.0.18_amd64.deb (74 MB). Install it with sudo apt install ./simplymail_1.0.18_amd64.deb. It won't update itself; download new versions from this page.
